# 科研森林 Research Forest

A project to remind and incentivize regular academic literature reading.

一个只在手机上使用的科研习惯 App：每周选几天作为科研日，按课题布置论文阅读清单；读完后和 AI 一问一答，确认真正读懂；读通的论文会在“科研森林”里长成一棵树。积累够了，AI 会结合课题要求布置一个科研任务。

所有数据只保存在你自己的手机里，不需要注册账号，也没有服务器。

**当前版本：1.4.0**

---

## 功能

### 今天
- 每周自选科研日（默认 2 天），本周和下周可以分别调整。
- 科研日自动生成 3–5 篇的阅读清单，按篇幅和优先级排序；没读完的自动顺延到下一个科研日。
- 灰色为未读，黄色为在读，绿色为已读通。

### 读后问答
- 导入论文 PDF（从 iPhone“文件”App 选取），App 在手机上提取全文。
- AI 依次提出 3 道理解题：核心结论、研究方法、与你课题的联系。答错了 AI 会纠正，你觉得理解了就进入下一题。
- 然后你向 AI 提 3 个问题，AI 依据论文内容回答。
- 3 + 3 全部完成后播放庆祝动画，论文标绿。

### 课题数据库
- **文献**：手动添加、修改、删除，或设为“暂缓”。
- **资料**：上传课题已有的内容（数据说明、数据样例、论文草稿、老师材料、文献清单等）。PDF、Word、TXT、Markdown、CSV、代码可读取文字，勾选“供 AI 参考”后 AI 会参考；文献清单可一键提取其中的文献。
- **推荐**：按课题关键词检索 OpenAlex，优先设置中指定的作者和机构，并避开“不推荐的方向”。
- **老师意见**：记录点评和要求，AI 布置阅读和任务时会遵守。
- **课题信息**：简介、数据说明、检索关键词、不推荐的方向。

### 我的科研森林
- Forest 风格的月历：读通论文的日子长出一棵大树，投入越多树越大。
- 可以手动记录“这天科研了”（选投入时长、写做了什么）。
- 显示总棵数、读通篇数和连续完成的科研日。

### 科研任务
- 累计完成一定数量的科研日或论文后（可在设置中调整），AI 结合读过的论文和老师要求布置一个任务：数据分析、写作、PPT、方法复现等。
- 提交产出后可以请 AI 点评。

### 多课题
- 顶部按钮切换本次科研日研究的课题；在“设置 → 课题”中新建、修改或删除课题。

### 其他
- **AI 模型可切换**：DeepSeek、通义千问、Kimi、智谱 GLM、Claude，或任意 OpenAI 兼容接口。API Key 只保存在手机上。
- **日历提醒**：把未来 8 周的科研日添加到 iPhone 自带“日历”，在科研日早上和前一晚提醒。
- **备份**：导出、导入备份文件。
- **更新说明**：每次更新后第一次打开会弹出本次修复和新增的内容。

## 安装到 iPhone

1. 用 iPhone 的 **Safari** 打开本项目的 GitHub Pages 网址。
2. 点底部 **分享按钮 → 添加到主屏幕**。
3. 之后从主屏幕图标打开。

## 第一次使用

1. **设置 → AI 模型**：选择模型，填入 API Key，点“测试连接”。
2. **设置 → 日历提醒**：点“添加到日历”。如果在主屏幕的 App 里点了没反应，用 Safari 打开同一网址再点一次。
3. **设置 → 课题**：新建你的课题，然后在“文献 → 课题信息”里填写简介和检索关键词。
4. 在“文献”里添加论文、上传资料、记录老师意见。

## 数据与隐私

- 课题、文献、笔记、PDF、资料、问答记录、森林和任务**全部保存在手机本地**（浏览器的 IndexedDB），不会上传到 GitHub 或任何服务器。本仓库只包含 App 的通用代码。
- 使用问答、任务、提取文献等 AI 功能时，相关的论文内容、笔记、老师意见和资料摘录会发送给你选择的模型服务商处理。不希望外传的内容，可以不勾选“供 AI 参考”，或把老师意见写得概括一些。
- **请勿把导出的备份文件上传到 GitHub 或公开的地方**，里面包含你的全部笔记和课题内容。

### 以下操作会清空数据，请先导出备份
- 删除主屏幕上的 App 图标；
- 在 iPhone“设置 → Safari → 高级 → 网站数据”中删除本网站的数据；
- 更换网址（例如换了 GitHub 账号）；
- 在 App 中导入备份（会覆盖现有数据）。

更新 App（替换本仓库的文件）**不会**影响手机里的数据。

## 开发

需要 Node.js 18 或以上。

```bash
npm install        # 安装依赖
npm run dev        # 本地预览
npm run build      # 打包，结果在 dist 文件夹
```

发布新版本：
1. 修改 `src/changelog.js`：把 `APP_VERSION` 改成新版本号，在 `CHANGELOG` 最前面写上修复和新增的内容。
2. 运行 `npm run build`。
3. 删除仓库中的 `assets` 文件夹，把 `dist` 里的全部内容上传覆盖，提交。
4. 等 GitHub Pages 部署完成（Deployments 显示绿色对勾）后，在手机上关闭并重新打开 App。

| 文件 | 作用 |
|---|---|
| `src/changelog.js` | 版本号与更新说明 |
| `src/prompts.js` | 给 AI 的提示词：出题、回答、任务与点评 |
| `src/store.jsx` | 科研日、阅读清单、统计的逻辑 |
| `src/openalex.js` | 文献检索与打分 |
| `src/materials.js` | 资料上传与文字提取 |
| `src/components/` | 各个页面 |
| `src/styles.css` | 颜色与样式 |

## 已知限制

- **没有推送通知**：没有服务器，改用日历提醒。
- **部分模型可能连不上**：App 在手机上直接调用模型接口，有的服务商会拦截网页请求。请用“测试连接”确认；如都连不上，需要加一个只转发请求的小服务。
- **中文文献**：OpenAlex 对中文期刊收录不全，知网文献需要手动添加。
- **期刊质量**：推荐打分基于被引次数、发表年份和指定作者 / 机构，不是官方影响因子。
- **扫描版 PDF**：无法提取文字，问答只能依据书目和笔记。
- **备份不含原文件**：备份包含提取出的全文和资料文字，不含 PDF 和资料的原文件。
