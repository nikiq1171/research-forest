# research-forest
A project to remind and incentivize regular academic literature reading.

# 科研森林

只在手机上用的科研习惯 App：每周选 2 个科研日，按课题数据库布置 3–5 篇论文，读完后和 AI 做 3 + 3 问答，读通的论文在“科研森林”里长成树；读够了就布置科研任务。所有数据只存在手机本地。

## 第一次使用

0. **导入课题数据**：把数据存到 iPhone 的“文件”App（例如通过微信“用其他应用打开 → 存储到文件”，或 iCloud 云盘），然后在 App 里点 **设置 → 备份 → 导入备份** 选择它。导入后会出现预置的文献、你的笔记和老师意见。
1. **设置 → AI 模型**：选择模型（建议先用 DeepSeek），填入 API Key，点“测试连接”。如果提示连不上，换一个模型试试（详见第五节）。
2. **设置 → 日历提醒**：选好提醒时间，点“添加到日历”，在弹出的页面点“全部添加”。如果在主屏幕的 App 里点了没反应，用 Safari 打开同一网址再点一次。
3. **今天**页：调整本周和下周的科研日。科研日打开 App 会自动生成阅读清单。
4. 每完成一个科研日，到 **设置 → 备份** 导出一次备份，存到“文件”App 或 iCloud 云盘。

## 主要功能

- **今天**：当天的阅读清单（灰色未读、黄色在读、绿色读通），没读完的会顺延到下一个科研日；本周和下周科研日的选择。
- **论文详情**：导入 PDF（从“文件”App 选取）、写笔记、读后问答。AI 先问你 3 道理解题，答错了会纠正，你觉得理解了就点“下一题”；然后你问它 3 个问题。全部完成后播放庆祝动画，论文标绿。
- **文献**：课题数据库，包括文献、资料、OpenAlex 推荐、老师意见与要求、课题信息（简介、数据、检索关键词、不推荐的方向）。
- **资料**：上传课题已有的内容（数据说明、数据样例、论文草稿、PPT、老师材料、文献清单等）。PDF、Word、TXT、Markdown、CSV（前 60 行）、代码会读取文字；勾选“供 AI 参考”后，AI 出题、回答和布置任务时会参考。文献清单类文件可以一键“提取其中的文献”加入文献库。单个文件不超过 50 MB。
- **森林**：Forest 风格的科研日历。读通论文或手动记录的日子长出一棵占满格子的大树，投入越多树越大；日期旁的小绿点是计划中的科研日。点任意一天可以手动记录“这天科研了”（选投入时长、写做了什么）。
- **任务**：累计 4 个科研日或读通 10 篇后，AI 结合老师的要求布置一个科研任务；提交产出后可以请 AI 点评。
- **多课题**：顶部的课题按钮可以切换本次研究的课题；新课题在“设置 → 课题”里新建。

## 用 VS Code 修改和开发

需要先安装 Node.js（18 或以上）。

```bash
npm install        # 安装依赖
npm run dev        # 本地预览，终端会显示网址
npm run build      # 打包，结果在 dist 文件夹
```

改完后重新 `npm run build`，把新的 `dist` 内容再上传到 GitHub 仓库覆盖即可。手机上的 App 会在下次打开时自动更新，数据不受影响。

主要文件：

| 文件 | 作用 |
|---|---|
| `src/seed.js` | 新用户的空白示例课题（不含任何个人内容） |
| `src/prompts.js` | 给 AI 的提示词：出题规则、回答规则、任务与点评 |
| `src/store.jsx` | 科研日、阅读清单、统计的逻辑 |
| `src/openalex.js` | 文献检索与打分（优先作者、优先机构在设置里指定） |
| `src/components/` | 各个页面 |
| `src/styles.css` | 颜色与样式 |

## 已知限制

- **推送通知**：没有服务器，无法推送，用日历提醒代替。
- **部分模型可能连不上**：App 在手机上直接调用模型接口，有的服务商会拦截来自网页的请求。Claude 明确支持；DeepSeek、通义千问、Kimi、智谱请用“测试连接”确认。如果你常用的模型都连不上，需要加一个只转发请求的小服务（例如 Cloudflare Worker）。
- **中文文献**：OpenAlex 对中文期刊收录不全，知网文献需要手动添加。
- **期刊质量**：推荐打分用被引次数、发表年份和是否为北大作者，不是官方影响因子。
- **扫描版 PDF**：无法提取文字，问答只能依据书目和笔记。
- **数据安全**：删除主屏幕上的 App、换手机或清理 Safari 网站数据都会清空记录，请定期导出备份。备份里包含已提取的全文和资料文字，但不含 PDF 和资料的原文件。
